# Server Grid (Fabric 1.21.11)
Multiplayer-Serverliste als 3er-Raster mit Suchfeld oben.
- Klick = auswählen, Doppelklick = beitreten, Mausrad = scrollen
- Die normalen Buttons unten (Beitreten, Bearbeiten, ...) funktionieren wie gewohnt.

Build: Push auf GitHub -> Actions -> `build` -> Artifact `servergrid-jar`.
